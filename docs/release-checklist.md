# 출시 체크리스트

Chrome 웹 스토어와 App Store 등록까지 남은 일. 코드 작업은 대체로 끝났고,
남은 것은 계정·결제·실기기 확인처럼 저장소 밖에서 해야 하는 것들이다.

관련 문서: [`store-listing.md`](store-listing.md) (대시보드 입력 문구),
`dist/privacy.html` · `dist/privacy-en.html` (개인정보처리방침)

---

## A. 출시 전 반드시

- [ ] **방침의 플레이스홀더 채우기** — `dist/privacy.html`과 `privacy-en.html`의
      `[운영자명]`, `[문의 이메일]`. 상단 주황색 안내 상자도 삭제한다.
      모바일 앱을 먼저 내지 않는다면 제목의 "및 모바일 앱" 표기도 정리.
- [ ] **방침 배포** — `firebase deploy --only hosting` →
      `https://language-helper-d1de6.web.app/privacy.html`로 열리는지 확인
- [ ] **Chrome 웹 스토어 개발자 등록** (1회 US$5)
- [ ] **확장 제출** — `npm run package` → `build/english-helper-<버전>.zip` 업로드,
      `store-listing.md`의 권한 정당화·데이터 공시·설명문 붙여넣기
- [ ] **Apple Developer Program 가입** (연 US$99) — **승인 대기가 있으므로
      확장 제출과 동시에 시작**한다. 이것만 기다림을 줄일 수 없다.
- [ ] **스크린샷 촬영** (1280×800, 최대 5장) — 찍을 화면 목록은
      `store-listing.md` 마지막 절. 저작권 있는 영상이 크게 나오지 않게.
- [ ] **App Store Connect 앱 레코드 생성** → Xcode 아카이브 → TestFlight →
      개인정보 레이블·연령 등급·심사용 데모 계정 입력 → 제출

## B. 아직 검증되지 않은 것

출시 전에 한 번씩은 실제로 해봐야 한다.

- [ ] **실기기에서 계정 삭제 1회 실행** — 가장 중요하다. Firebase 재인증과
      Firestore 삭제 권한은 테스트의 Fake로 검증되지 않는다. 삭제 후
      Firestore 콘솔에서 `users/{uid}` 아래가 비었는지도 확인한다.
- [ ] **툴바 팝업 전체 동작** — 토글 반영, 저장 목록 개수와 열기,
      마스터 on/off, 비지원 사이트에서의 표시. `chrome-extension://` URL이라
      브라우저 자동화로는 열 수 없어 미검증으로 남았다.
- [ ] **쿠팡플레이 프리롤 광고 구간** — 광고가 붙는 콘텐츠에서 타임라인이
      어떻게 되는지 확인하지 않았다. Disney+에서 프로모 스트림이 본편 마스터를
      덮어쓰던 것과 비슷한 함정이 있을 수 있다.

## C. 결정이 필요한 것

- [ ] **스크립트 패널이 닫혀 있을 때의 설정 진입로** — 지금은 패널 헤더의
      설정 버튼이 유일한 경로라, 패널을 닫으면 자막 설정에 갈 방법이 없다.
      팝업에 한 줄 더하면 해소된다(`EH_OPEN_SETTINGS` 핸들러는 이미 있음).
      다만 자막 설정을 팝업에서 빼기로 한 결정과 상충한다.
- [ ] **툴바 아이콘 ON 배지** — 디자인 §1k에는 있으나 구현하지 않았다.
      `chrome.action.setBadgeText`로 추가 가능.
- [ ] **§1j 중복 금지 원칙** — 설계 문서는 "팝업과 상단 바가 같은 항목을
      갖지 않는다"고 했는데, 현재 팝업에 저장 목록이 있다. 상단 바를 없앴으니
      중복은 아니지만, 원칙을 어떻게 정리할지는 미결.
- [ ] **스토어 설명문 영문판** — 방침은 한·영 모두 있으나 설명문은 한국어뿐.

## D. 정리하면 좋은 것 (급하지 않음)

- [ ] `firebase-config.js` — 어디서도 import하지 않는 잔재.
      실제 설정은 `cloud/config.js`에 있다.
- [ ] `flutter_integration.dart` — `mobile/`이 생기기 전의 예제 파일.
- [ ] `ui/tokens.css` 주석 — "툴바 팝업은 밝은 앱 테마를 쓴다"고 되어 있으나
      실제 팝업은 §1k를 따라 다크로 만들었다.
