# Chrome 웹 스토어 등록 자료

대시보드에 그대로 붙여 넣을 문구 모음. 모든 내용은 코드에서 확인한 사실만
담았고, 개인정보처리방침(`dist/privacy.html`)·데이터 공시와 서로 어긋나지
않게 맞춰 두었다. 셋 중 하나를 고치면 나머지도 같이 본다.

---

## 1. 권한 정당화

대시보드의 "권한 사용 사유"에 항목별로 입력한다. 각 문구는 **무엇을 위해
쓰는지**와 **그것 없이는 왜 안 되는지**를 한 문장씩 담는 형태로 썼다.

### storage

> 자막 표시 설정(모국어, 표시 모드, 글자 크기), 기능 on/off 상태, 사용자가
> 저장한 문장과 단어의 로컬 사본, 그리고 서버에 아직 올리지 못한 항목의
> 동기화 대기열을 기기에 보관합니다. 이 저장소가 없으면 설정이 페이지를
> 새로고침할 때마다 초기화되고, 오프라인에서 저장한 항목이 유실됩니다.

### tabs

> 두 가지 용도로만 사용합니다. (1) 툴바 팝업이 현재 탭의 주소를 읽어 지원
> 플랫폼인지 판별하고 그에 맞는 상태를 표시합니다. (2) 설정을 변경했을 때
> 지원 사이트의 탭에만 메시지를 보내 즉시 반영합니다. 방문 기록을 수집하거나
> 저장하지 않으며, 지원 플랫폼 네 곳 외의 주소는 읽은 즉시 버립니다.

### alarms

> 15분마다 한 번 백그라운드 동기화를 실행해, 저장한 항목을 서버와 맞춥니다.
> MV3 서비스워커는 유휴 상태에서 종료되므로 setTimeout/setInterval로는 주기
> 작업을 유지할 수 없어 alarms가 필요합니다.

### 호스트 권한 — youtube.com, netflix.com, disneyplus.com, coupangplay.com

> 확장의 핵심 기능이 동작하는 곳입니다. 영상 페이지에서 자막 데이터를 읽어
> 영어와 번역을 함께 보여주고, 전체 자막을 스크립트 패널로 제공합니다.
> 네 곳 모두 자막을 가져오는 방식이 달라 사이트별 처리가 필요합니다.
> 각 사이트의 영상 재생 페이지에서만 동작하며, 자막 내용은 기기에서만
> 처리하고 외부로 전송하지 않습니다.

### 호스트 권한 — identitytoolkit.googleapis.com, securetoken.googleapis.com, firestore.googleapis.com

> 저장한 문장과 단어를 모바일 앱과 동기화하기 위한 Firebase 엔드포인트입니다.
> 각각 로그인 처리, 인증 토큰 갱신, 데이터 저장에 사용합니다. 로그인하지
> 않으면 호출되지 않으며, 확장의 자막 기능은 로그인 없이도 모두 동작합니다.

### 호스트 권한 — language-helper-d1de6.web.app

> 영어 사전 데이터를 내려받는 자체 호스팅 서버입니다. 사전은 알파벳 앞글자
> 기준으로 나뉜 묶음 파일로 제공되며, 확장은 필요한 묶음을 받아 기기에
> 저장하고 조회는 기기 안에서 수행합니다. 사용자가 찾아본 단어를 서버로
> 보내지 않습니다.

### 원격 코드 사용

> 사용하지 않습니다. 모든 스크립트가 패키지에 포함되어 있으며, 외부에서
> 코드를 받아 실행하지 않습니다. 서버에서 받는 것은 JSON 사전 데이터와
> 자막 텍스트뿐입니다.

### 단일 목적 서술

> 영상 스트리밍 사이트에서 영어 자막 학습을 돕습니다. 이중 자막 표시,
> 전체 스크립트 열람, 모르는 표현 저장과 복습이라는 하나의 목적을 위한
> 기능으로 구성되어 있습니다.

## 2. 데이터 사용 공시

대시보드의 체크 항목과 그 근거. 판단 기준은 **사용자가 저장 버튼을 누른
항목만 서버로 전송된다**는 것이다.

| 항목 | 수집 | 근거 |
|---|---|---|
| 개인 식별 정보 | **예** | 로그인 시 이메일 주소 |
| 인증 정보 | **예** | 로그인 토큰(기기 보관). 비밀번호는 Firebase가 처리하며 확장이 보관하지 않음 |
| 웹사이트 콘텐츠 | **예** | 사용자가 저장한 자막 문장과 그 출처(콘텐츠 제목·재생 시점) |
| 사용자 활동 | **아니요** | 클릭·스크롤·조회 단어 등 행동을 수집하지 않음 |
| 웹 방문 기록 | **아니요** | 방문한 페이지 목록을 수집·저장하지 않음 |
| 위치 / 건강 / 금융 / 개인 통신 | **아니요** | 해당 없음 |

서약 세 가지 모두 **해당**한다 — 데이터를 판매하지 않고, 단일 목적과
무관한 용도로 쓰지 않으며, 신용 평가에 사용하지 않는다.

> **"웹사이트 콘텐츠"를 아니요로 체크하지 말 것.** 저장한 항목에
> `content_title`(시청 중이던 콘텐츠 제목)이 함께 보관되므로 해당한다.
> 방침 2절에도 같은 내용이 적혀 있어, 어긋나면 바로 드러난다.

개인정보처리방침 URL: `https://language-helper-d1de6.web.app/privacy.html`

## 3. 스토어 등록정보

### 이름

```
English Helper — 이중 자막 영어 학습
```

### 요약 (132자 이내)

```
YouTube · Netflix · Disney+ · 쿠팡플레이에서 영어와 한국어 자막을 함께 보고, 모르는 표현을 저장해 복습하세요.
```

### 상세 설명

```
영어 자막만 켜면 놓치고, 한국어 자막만 켜면 영어가 안 들립니다.
English Helper는 둘을 함께 보여줍니다.

■ 지원 플랫폼
YouTube · Netflix · Disney+ · 쿠팡플레이

■ 주요 기능

이중 자막
영어와 모국어를 영상 위에 함께 표시합니다. 글자 크기, 한 줄에 보여줄 분량,
영어만 볼지 번역도 볼지를 원하는 대로 맞출 수 있습니다.

전체 스크립트
영상의 모든 자막을 오른쪽 패널에서 한눈에 봅니다. 재생 위치가 자동으로
따라가고, 읽고 싶은 줄을 누르면 그 장면으로 바로 이동합니다. 스크롤해서
다른 곳을 살펴보는 동안에는 자동 따라가기가 잠시 멈춥니다.

단어와 문장 저장
모르는 단어를 누르면 뜻이 바로 나옵니다. 마음에 든 문장은 저장해 두면
어떤 작품의 어느 장면이었는지와 함께 보관됩니다.

스크립트 내보내기
전체 자막을 HTML이나 PDF로 저장해 따로 공부할 수 있습니다.

모바일 앱 연동
같은 계정으로 로그인하면 저장한 표현이 앱으로 넘어가, 플래시카드로
복습할 수 있습니다.

■ 개인정보

저장 버튼을 누른 항목만 서버로 전송됩니다. 재생 중 표시되는 자막은
기기에서만 처리하며 전송하지 않고, 사전에서 찾아본 단어도 보내지 않습니다.
무엇을 시청했는지 자동으로 기록하지 않으며, 광고를 보여주거나 이용자를
추적하지 않습니다.

로그인은 기기 간 동기화를 원할 때만 필요합니다. 로그인하지 않아도 자막
기능은 모두 사용할 수 있습니다.

개인정보처리방침: https://language-helper-d1de6.web.app/privacy.html
```
