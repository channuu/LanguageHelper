# 타이머 화면(1e) 재설계

**날짜:** 2026-08-20
**상태:** 승인됨
**상위 문서:** `docs/superpowers/specs/2026-08-09-study-timer-design.md`, Claude Design 목업 `English Helper UI.dc.html` §1e

---

## 1. 배경

`mobile/lib/features/timer/timer_screen.dart`는 기능적으로는 완성돼 있다(시작/일시정지/재개/종료, 주간 목표 진행률, 주/월/년+그래프/숫자 기록 보기). 목업 §1e는 이 화면의 시각 언어를 디자인 토큰에 맞추고, 상단 타이머 카드와 주간 목표 카드의 레이아웃을 재구성한다. 데이터 모델·리포지토리 변경은 없다 — 이번은 순수 리스타일 + 레이아웃 작업이다.

## 2. 범위

- **포함:** 타이머 카드(상태 배지+시계+오늘 누적+버튼) 재설계, 주간 목표 카드를 7일 막대그래프 형태로 재구성, "최근 세션" 목록(개별 세션 항목 표시, 신규) 추가, 기존 `TimerHistoryView`(주/월/년 + 그래프/숫자 전환)는 기능 유지하며 카드 스타일만 디자인 토큰에 맞춰 재입힘.
- **제외:** 새 리포지토리 메서드, 스키마 변경, `TimerHistoryView`의 주/월/년·그래프/숫자 전환 기능 제거(목업에 없지만 기존 기능이라 유지).

## 3. 화면 구조

### 3.1 타이머 카드

- 상태 배지(pill): 실행 중이면 "학습 중"(오렌지 배경 `AppColors.accent`+ink 텍스트+오렌지 점), 일시정지면 "일시정지"(연회색 배경+회색 텍스트+회색 점). 세션이 아예 없으면(시작 전) 배지 자체를 숨긴다(목업은 이 상태를 가정하지 않음 — §3.3에서 결정한 대로 상태 3종 유지).
- 시계: `HH:MM:SS`, 기존 `_format()` 그대로 재사용, 폰트만 Schibsted Grotesk 56px 세미볼드 + tabular-nums로 재스타일.
- "오늘 누적 {N}시간 {M}분": 오늘(자정~지금) 종료된 세션들의 합 — 신규 계산 로직(§3.4).
- 버튼: §3.3에서 정한 대로 세션 없음일 때 "시작" 단일 버튼, 세션 있을 때(실행/일시정지 무관) 토글 버튼(실행 중="일시정지", 일시정지="재개") + "종료" 버튼 항상 같이.

### 3.2 주간 목표 카드

- 헤더: "이번 주 목표" + "{누적}:{목표} " (`MM:SS`가 아니라 `H:MM` 형식, 예: "3:12 / 5:00" — 시간:분).
- 목표 미설정 시: 기존 "이번 주 목표를 설정해보세요" + "목표 설정" 텍스트버튼 그대로 유지(목업엔 이 상태가 없어 기존 UI를 재스타일만).
- 목표 설정됨: 요일별(월~일) 7개 막대그래프. 막대 높이는 그 요일 누적 학습 시간 ÷ 하루 최대치(그 주 최댓값 또는 목표/7 중 큰 값) 비율. 오늘 막대만 `AppColors.accent`, 나머지 학습 기록 있는 요일은 연한 오렌지 틴트(`#FFBC8F`, 목업 `oklch(0.86 0.11 50)`), 기록 없는 날은 `#F0F2F7`. 요일 라벨도 오늘만 진한 잉크색, 나머지는 회색.
- 하단: "주 {N}시간 목표까지 {남은시간} 남았습니다" 또는 목표 달성 시 다른 문구(§4).

### 3.3 타이머 상태 (확정)

세션이 없을 때는 기존처럼 "시작" 단일 버튼만 노출한다. 세션이 시작된 이후(실행 중이든 일시정지든)부터 목업의 토글+종료 버튼 쌍을 적용한다. 즉 `_buildButtons`의 3분기 구조(없음/실행/일시정지)는 유지하되, 실행·일시정지 두 분기의 시각 스타일만 목업에 맞춘다.

### 3.4 "오늘 누적" 계산

새 헬퍼로 오늘(자정 기준) 종료된 세션들의 `durationSeconds` 합을 구한다. 현재 진행 중인 세션(아직 미종료)의 경과 시간은 포함하지 않는다 — 화면 상단 시계가 이미 실시간으로 그 값을 보여주고 있으므로 이중 표시를 피한다.

### 3.5 최근 세션 목록 (신규)

`StudySession`에는 `title` 필드가 없다(어떤 콘텐츠와도 연결되지 않은 순수 시간 기록). 목업의 `s.title`/`s.when` 두 줄을 다음으로 매핑한다: 첫 줄 = 날짜(예: "8월 15일"), 둘째 줄 = 시작~종료 시각 범위(예: "오후 3:20 - 4:05"). 우측 = 소요 시간("45분"). 최근 종료된 세션 최대 5개를 최신순으로 보여준다. 세션이 하나도 없으면 이 섹션 자체를 숨긴다(빈 상태 문구 없음 — 목업에 없는 요소를 새로 만들지 않음).

## 4. 에러 처리

- 주간 목표 미설정: 기존 카드 그대로.
- 이번 주 학습 시간이 이미 목표를 넘었으면 "주간 목표를 달성했어요! 🎉"로 문구 전환(막대그래프 자체는 그대로 표시).
- "최근 세션"은 데이터 없으면 섹션 자체 미노출(§3.5).

## 5. 테스트

- 상태별 버튼 구성(없음=시작만, 실행 중=일시정지+종료, 일시정지=재개+종료) 위젯 테스트 — 기존 테스트 재사용 가능한 부분은 그대로, 스타일 변경으로 텍스트 라벨 자체는 안 바뀌므로 대부분 회귀 없이 통과해야 함.
- "오늘 누적" 계산: 오늘 종료된 세션만 합산되는지, 어제 세션은 제외되는지, 진행 중인 세션은 포함 안 되는지.
- 주간 막대그래프: 오늘 막대와 다른 날 막대의 색이 다른지, 기록 없는 날은 회색인지.
- 목표 달성 시 문구가 "달성했어요"로 바뀌는지.
- 최근 세션 목록: 최대 5개까지만 보이는지, 최신순 정렬인지, 세션이 없으면 섹션이 안 보이는지.

## 6. 범위 밖 (재확인)

- 새 리포지토리 메서드/스키마 변경
- `TimerHistoryView`의 주/월/년·그래프/숫자 전환 기능 제거
- 세션에 콘텐츠/제목 연결 기능 추가
